# 初恋 · 旧爱 · 新欢｜电影制作档案

静态网站展示完整成片、制作提示词与图片，以及项目复盘手记。

## 本地预览

```powershell
python -m http.server 8080
```

浏览器打开 `http://localhost:8080/`。

## 提示词档案

提示词档案提供两种视图：

- **思维导图**：从起点开始点击卡片，按真实制作关系逐步展开；真实分叉会上下生长。
- **隧道漫游**：按全部图片出现顺序进行沉浸式漫游。

思维导图支持：

- 按住空白处拖动画布；
- 使用滚轮缩放；
- “当前总览”显示全部已展开节点；
- “恢复原样”返回最近阅读节点；
- “全部收起”重新从起点开始；
- 点击“查看内容”打开完整图片、提示词和批注。

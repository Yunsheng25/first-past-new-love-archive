# 《初恋·旧爱·新欢》复盘手记阅读器设计

## 目标

把现有复盘手记从狭小的分页阅读区改造成适合桌面端长文阅读的双页式阅读器，同时保留原文顺序、原案例媒体与原批注关系。读者可以在不离开手记的前提下阅读、翻页、查看案例、展开互动导图，并对任意文字进行高亮和批注。

## 已确认的阅读形态

- 桌面端采用铺满主要视口的双页书本布局。
- 普通模式保留顶部的返回、章节、阅读设置和“我的笔记”入口。
- 沉浸模式隐藏顶部界面，只留下双页正文、左侧索引条和低干扰的退出按钮。
- 左侧继续使用网站现有索引条及其原有交互：扩大感应范围、光带跟随鼠标、当前项与相邻项伸展、悬停显示章节内容。
- 正文默认保持较大的宋体字号和舒适行距；设置中允许调整字号。
- 支持浅色纸张与深色纸张两种阅读主题，并记住读者的选择。

## 翻页

- 保留上一页、下一页按钮。
- 鼠标滚轮向下翻到下一双页，向上翻到上一双页。
- 滚轮翻页带阈值与节流，防止一次滚动连续跳过多页。
- 使用具有正反面、阴影和中缝变化的真实纸张翻页动画。
- 每次双页所需的正文和案例媒体在翻页完成前准备好，避免翻过去以后出现空白。

## 高亮、读者批注与汇总

- 用户先用鼠标自由选择任意字词或句子，而不是整段操作。
- 选区附近出现“高亮”和“添加批注”两个操作。
- 高亮只覆盖实际选中文字。
- 添加批注时保留选中文本并打开批注输入面板。
- 高亮、批注、阅读主题、字号和阅读进度默认保存在当前浏览器本地，不需要登录。
- “我的笔记”汇总页分为全部、仅高亮、有批注三类，并显示原文位置、引用和批注内容。

## 作者原有案例批注

“作者案例批注”和“读者自己添加的批注”是两套不同内容：

- 原手记中属于同一 callout 的标题、图片、视频和解释文字必须保持原顺序并放在同一个“批注”框里。
- 正文中的批注框采用紧凑预览：多张图片可以左右排列，视频保留控制条，文字不与媒体拆开。
- 批注框提供“查看案例详情”入口。
- 详情层放大整个批注框，完整展示标题、媒体与解释文字。
- 详情层内的单张图片还能继续点开放大查看原图。
- 关闭原图后回到案例详情；关闭详情后回到原来的阅读位置。
- 不擅自移动、替换、合并或删除任何原案例媒体。

## 互动导图

- “生图”“视频”“剪辑”部分原本作为总结的思维导图图片仍留在原文位置和原来的图片框中。
- 点击图片框后直接在手记内进入互动导图，复用现有“生图过程拆解”的拖动、缩放、节点展开方式。
- 不另开独立展示页面，不把导图从原文抽离。
- 视频流程导图补齐与生图、剪辑一致的互动模型。
- 退出互动状态后回到同一页、同一滚动位置。

## Markdown 与内容校验

- 修复源手记中不配对的 `**`，确保加粗内容正常显示，不在页面上暴露 Markdown 符号。
- 全篇检查所有加粗标记，而不是只修截图中的一处。
- 构建后的复盘数据不得出现未闭合的加粗标记。
- 验证所有图片、视频和批注子项的数量、顺序及上下文与源手记一致。

## 加载与失败处理

- 进入复盘路线时先准备当前双页，随后按阅读顺序准备后续双页。
- 翻页前确保目标双页的图片完成解码，视频至少取得元数据。
- 加载期间显示与网站风格一致的页内准备状态，不显示破损图片或空白案例框。
- 媒体失败时在原位置提供重试，不跳过或替换媒体。

## 验收重点

1. 桌面端双页阅读空间明显大于旧版，沉浸模式没有顶部导航。
2. 左侧索引条保持现有动效和章节提示能力。
3. 按钮、滚轮都能稳定触发真实翻页，且不会连续误翻。
4. 任意文字选区可以分别高亮或添加批注，刷新后仍可恢复。
5. 作者案例批注中的媒体和文字始终在同一框内，详情与原图均可逐级查看。
6. 三张流程总结图都能在原框内进入互动导图。
7. 全篇不再出现裸露的 `**`。
8. 图片和视频不会在翻页后长时间保持空白。

# 全站素材预加载页设计

## 目标

访客进入网站时先看到加载页。首页背景影像等当前入口必需素材成功进入浏览器缓存后，加载页淡出并展示当前路由。其余图片、音频和视频在网站开放后以低并发继续进入浏览器缓存，避免510MB全量素材阻塞首次进入。

## 加载流程

1. HTML 首屏直接渲染独立加载界面，避免 JavaScript 下载与执行前出现纯黑空白。
2. 构建脚本生成稳定的素材清单，记录每个公开素材的路径与字节数。
3. 浏览器先请求当前入口的必需素材；加载页显示这部分的真实文件进度、累计字节进度和失败重试状态。
4. 必需素材成功后挂载现有路由，再以短暂淡出动画移除加载层。
5. 剩余素材使用低并发后台预载，不阻塞路由交互，也不因单项失败重新遮挡网站。
6. 入口必需素材单项失败时自动重试；仍失败时提供“直接进入”和“重新加载”两个选择。

## 缓存与重复访问

资源请求使用浏览器 HTTP 缓存。再次访问时仍执行完整性检查，但已缓存的素材应快速命中本地缓存。加载器不把 510MB 素材同时保存在 JavaScript 内存中，只消费响应数据并让浏览器管理磁盘缓存。

## 交互与视觉

加载页沿用网站的黑金电影档案风格，主体为一条斜向缓慢穿过画面的影像长卷，包含项目标题、细线进度轨道、百分比、已加载容量和当前素材阶段。

长卷保持单层、清晰且不拥挤，并锁定在画面中央横向穿过。尚未加载的卡片呈低饱和暗片；素材成功进入缓存后，对应卡片逐张显影为清晰图片并保留点亮状态。鼠标使用现有圆环语言，移动时形成一圈暗房显影波纹；波纹靠近卡片时，卡片短暂抬起、增亮并增强清晰度。鼠标移动只产生幅度很小的纵深偏移，不改变长卷的中央构图。

动画尊重减少动态效果设置。加载期间不显示正文或可点击入口。

## 验证

- 素材清单覆盖所有公开素材且路径不存在遗漏。
- 当前入口的必需素材未完成时不挂载网站内容。
- 必需素材成功后只进入一次，后台预载不重新显示遮罩。
- 必需素材失败按限制次数重试，并在最终失败时提供重新加载或直接进入。
- 加载器销毁后不留下计时器、监听器或重复请求。
- 完整测试套件通过，并在本地模拟慢速与失败请求。

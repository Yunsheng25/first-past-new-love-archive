# 片后选择页圆形光标设计

## 决定

撤销片后选择页的 Splash Cursor 流体背景，改用此前交互小样 C 的圆形光标。

## 交互

- 仅在支持精细指针的桌面设备上隐藏系统光标并显示一个 42px 的暖白空心圆环。
- 圆环中心保留 3px 实心点，位置平滑跟随鼠标。
- 鼠标进入“复盘手记”或“提示词和图片”卡片时，圆环扩大到 76px，并带一层很淡的暖色透明底。
- 当前卡片向右移动 8px、轻微放大，箭头同步向右移动；不改变卡片排版。
- 鼠标离开片后选择页时隐藏自定义圆环并恢复状态。

## 边界与降级

- 首页、播放器、复盘阅读器和提示词隧道不使用该光标。
- 触屏、粗指针设备和不支持精细指针的设备保留系统光标。
- 系统启用减少动态效果时取消平滑追随，改为直接定位。
- 切换路由时删除事件监听并取消动画帧。

# 全站鼠标互动与复盘目录统一设计

## 目标

解决三个已确认的问题：

1. 单字动效必须精确碰到字符才触发，响应范围过小。
2. 复盘手记五个章节中，部分章节显示图片、部分章节显示数字占位，视觉规则不统一。
3. 除少数页面外，大部分页面的背景不响应鼠标，整体缺少连续的互动感。

## 文字动效：宽范围磁场

- 采用已确认的 B 方案。
- 鼠标距文字约 180px 时，附近字符提前响应，无需精确落在字符轮廓上。
- 距离鼠标越近的字符，上移、放大和暖色光晕越明显；影响随距离连续衰减。
- 动效继续保持单字反馈，不改成整句统一位移。
- 适用于所有当前带有 `data-character-motion` 的文字。
- 鼠标离开感应范围后，字符平滑恢复原样。
- 开启减少动态效果或使用非精确指针设备时，不运行磁场动画。

## 复盘手记目录：纯数字章节

- 采用已确认的 D 方案。
- 删除五个章节的图片预览和无图占位框。
- 每个章节统一显示大号 `01`—`05`、章节标题、页数和进入提示。
- 保留章节顺序、标题、阅读时长、页数和原有链接目的地。
- 悬停时整行产生轻微背景变化与内缩，不改变章节顺序。
- 移动端仍为单列目录，数字、标题和页数保持可读。

## 全站背景：高密度粒子吸附 V2

- 每个非影片播放页面安装同一套背景粒子系统。
- 桌面大屏最多约 320 颗粒子；粒子数量按视口面积计算，避免小屏使用同样密度。
- 粒子平时低速漂浮并维持各自的基础位置。
- 鼠标进入后形成约 310px 的引力范围：
  - 范围内粒子向鼠标加速聚拢；
  - 距离鼠标较近的粒子产生轻微环绕；
  - 粒子与鼠标之间出现低透明度连线；
  - 鼠标停止约 1.5 秒或离开页面后，粒子逐渐松散并返回基础位置。
- 粒子画布位于内容下方，不拦截链接、按钮、拖动和滚动。
- 各页面可通过透明度变量调节强度，但吸附逻辑保持一致：
  - 首页、片后选择、提示词总览和思维导图使用标准强度；
  - 复盘阅读页降低约 25% 视觉亮度，保证长文阅读；
  - 完整影片播放页不安装粒子，避免干扰播放器和增加性能开销。
- 原有圆环鼠标继续保留，粒子系统只负责背景。
- 使用非精确指针、开启减少动态效果或画布初始化失败时，页面使用原背景，不影响内容与操作。

## 架构

- 新建独立的全站背景模块，负责画布、粒子状态、指针监听、动画循环、尺寸变化和清理。
- 扩展文字动效模块，在挂载时监听文字容器附近的指针位置并按距离计算字符变化。
- 简化复盘目录生成逻辑，移除章节图片查找和预览标记。
- 路由渲染层统一挂载圆环光标与粒子背景，并在切换页面时完成清理，避免重复画布和动画循环。

## 性能与可访问性

- 画布设备像素比最多使用 2。
- 粒子数量设置硬上限，并根据视口面积缩放。
- 页面不可见时暂停动画，重新可见后恢复。
- 路由切换时移除全部事件监听并取消动画帧。
- 粒子画布标记为装饰内容，对辅助技术隐藏。
- `prefers-reduced-motion: reduce` 和粗指针设备直接使用静态回退。

## 验证

- 单元测试验证文字在字符外的感应范围内仍会响应，并在离开后恢复。
- 单元测试验证复盘目录不再输出图片、占位框或图片加载属性，且 01—05 顺序完整。
- 单元测试验证粒子数量上限、引力更新、静态回退、页面隐藏暂停及销毁清理。
- 路由测试验证除影片播放外的所有页面均挂载并清理背景系统。
- 桌面端检查首页、片后选择、复盘目录、复盘阅读、提示词总览和思维导图。
- 完整测试通过后推送 GitHub Pages，并核对线上脚本为最新版本。

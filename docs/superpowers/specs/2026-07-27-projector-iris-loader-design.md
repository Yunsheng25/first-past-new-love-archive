# 放映机光阑加载动画设计

## 目标

替换现有加载页中的横向胶片与暗室鼠标光束动画。保留当前关键资源优先加载、进度反馈、失败重试和直接进入功能。

## 视觉方向

- 主体采用已确认的 G 方案“放映机光阑”。
- 画面中心为缓慢呼吸的放映机镜头光阑，使用暖金色微光和深黑褐背景。
- 保留片名、档案年份、加载百分比和当前加载状态，排版保持克制。
- 不使用横向移动胶片、旋转条纹、大面积跟随光束或高密度粒子。

## 鼠标互动

- 采用已确认的 K 方案“玻璃显影镜”。
- 桌面端鼠标显示为一块半透明圆形镜片。
- 镜片经过背景时，只在镜片范围内显露隐藏的片名或档案纹理。
- 镜片本身使用低对比边缘、高透明度内层和轻微高光，不遮挡加载数字。
- 移动端与精确指针不可用的设备不显示镜片，加载动画仍可正常观看。

## 动效

- 光阑以约 3.4 秒周期缓慢呼吸。
- 玻璃镜片紧跟指针，不添加明显拖尾。
- 加载完成后沿用现有淡出转场进入网站。
- `prefers-reduced-motion` 开启时停止光阑呼吸，只保留静态构图和进度变化。

## 功能边界

- 不改变资源预加载策略。
- 不改变网站首页、成片、复盘手记或图片提示词页面。
- 不改变加载失败时的“重新加载”和“直接进入”操作。

## 验证

- 自动测试确认预加载进度、失败操作和退出清理仍然有效。
- 桌面端检查镜片跟随、局部显影及不会遮挡操作。
- 移动端检查无自定义镜片时的静态回退。
- 完整测试通过后再推送至 GitHub Pages。

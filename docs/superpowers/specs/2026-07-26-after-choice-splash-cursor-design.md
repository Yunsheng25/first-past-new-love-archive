# 片后选择页 Splash Cursor 动效设计

## 目标

在影片播放结束后的选择页中，为“复盘手记”和“提示词和图片”两个入口加入可被鼠标搅动的流体泼墨背景。动效应增强记忆、情绪与电影感，但不能影响卡片文字阅读、点击操作或页面性能。

## 范围

- 仅作用于 `#after` 片后选择页。
- 不修改首页、成片播放器、复盘阅读器和提示词隧道。
- 不改变两个入口的文字、位置、链接与现有视觉层级。

## 视觉设计

- 流体铺满片后选择页的背景区域，位于现有背景之上、内容卡片之下。
- 色彩限定为暗红、暖金和灰褐色，不使用默认彩虹或高饱和霓虹色。
- 鼠标快速移动时产生明显的流体拖曳、卷曲和扩散；鼠标停止后逐渐消散。
- 流体保持中低亮度，不能遮挡标题、说明文字和两个入口卡片。
- 卡片保留现有悬停反馈，不叠加夸张的倾斜、吸附或光标变形。

## 交互与生命周期

- 进入片后选择页时初始化流体画布。
- 指针在选择页移动时向流体模拟注入速度和颜色。
- 离开选择页或切换路由时停止动画并释放 WebGL 资源，避免后台持续耗电。
- 重新进入选择页时可重新初始化。
- 流体画布设置 `pointer-events: none`，不能阻断卡片链接、按钮或键盘操作。

## 性能与降级

- 桌面端使用用户给出的效果方向：`SIM_RESOLUTION=128`、高分辨率染料纹理、明显的拖曳力度和较慢消散。
- 根据设备像素比和视口大小限制画布实际分辨率，避免 4K 屏幕过度消耗显存。
- 低性能设备和窄屏设备降低染料分辨率、注入力度与更新频率。
- 当浏览器不支持 WebGL、创建上下文失败或发生运行错误时，隐藏画布并保留原有静态背景。
- 当系统启用 `prefers-reduced-motion: reduce` 时不启动流体模拟。

## 代码边界

- 新建独立的原生 JavaScript 流体模块，负责初始化、指针输入、动画循环和销毁。
- 片后页面渲染逻辑只负责挂载流体容器并调用模块，不把 WebGL 计算塞入现有视图模板。
- CSS 只负责画布层级、混合模式、透明度和降级样式。
- 不引入 React 运行时；现有网站是原生模块结构，效果以等价的原生 WebGL 实现接入。

## 验收标准

1. 鼠标在片后选择页移动时，背景产生连续、可见的流体泼墨响应。
2. 流体色彩符合暗红、暖金、灰褐色的项目调色，不出现彩虹霓虹。
3. 两张入口卡片始终清晰、可点击，键盘焦点不受影响。
4. 切换到复盘或提示词页面后动画停止；返回时恢复。
5. WebGL 不可用或减少动态效果开启时，页面保持原有静态外观且无报错。
6. 桌面端连续运行与频繁切换页面时不出现明显内存持续增长。

# 导图与复盘索引交互修正

## 目标

修正当前互动导图的层级、提示词流程图的分支方向、画布误选、圆环光标层级和复盘索引条的实用性。修改只处理用户指出的问题，不重新设计其他已确认内容。

## 复盘互动导图

- 生图总结图打开后，最先显示一个名为“生图过程拆解”的主干节点。
- 点击主干后，展开现有的“确定风格母图”和“生成具体画面”两支。
- 两支后续节点继续使用现有内容与层级，不删除、不交换、不重新概括。
- 剪辑互动导图保持现有内容结构，仅统一防误选与输入行为。

## 提示词流程图

- 主线仍严格按照素材原始制作顺序前进。
- 同一位置出现两条错误支线时，一条从主线上方向展开，一条从主线下方向展开。
- 错误支线结束后重新汇入正确主线。
- 不改变案例顺序、错误归属、节点内容、拖动、缩放、总览、恢复原样和详情弹层。

## 防误选与输入

- 导图画布、节点、连接线区域和复盘索引条禁止浏览器文字选中与拖拽选图。
- 只有主鼠标左键可以启动画布拖动或节点交互。
- 右键与中键不触发展开、拖动或选中。
- 按钮、详情弹层和正文阅读区域保留正常点击及必要的文字选择能力。

## 圆环光标层级

- 圆环光标继续全站显示。
- “返回篇目”等可点击控件始终绘制在圆环光标上方。
- 圆环保持 `pointer-events: none`，不得截获或遮挡按钮交互。

## 复盘索引条

- 默认状态保持安静，不添加持续流光、呼吸或无意义装饰动画。
- 每一个刻度仍分别代表章节、案例或页面，并保持原始顺序。
- 悬停或键盘聚焦某一刻度时：
  - 刻度平滑伸长并提高亮度；
  - 旁边浮出明确标签；
  - 标签包含所在序号以及对应章节、案例或页面内容；
  - 当前阅读位置仍有稳定但克制的状态区别。
- 点击刻度直接跳转到对应位置。
- 悬停离开后平滑恢复，不让索引条遮挡正文。

## 验证

- 为生图互动导图新增主干层级测试。
- 为错误支线上下分布增加布局测试。
- 为左键限定、禁止误选和右键不触发增加交互测试。
- 为索引标签的序号与具体内容增加数据及标记测试。
- 运行完整项目测试，并在桌面宽度下检查复盘阅读页和两类导图。

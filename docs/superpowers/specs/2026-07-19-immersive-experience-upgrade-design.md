# 《初恋旧爱新欢》网站沉浸体验升级设计说明

日期：2026-07-19

状态：视觉与交互方向已确认，待用户审阅本文

基础规格：`2026-07-18-first-love-project-site-design.md`

## 1. 本轮目标

本轮不改变网站已经确定的核心流程，而是在现有初版上解决四个体验问题：

1. 全站缺少连续的听觉氛围。
2. 完整成片播放器会让访客感觉被困住。
3. 复盘阅读器对比生硬、标题重复、翻页不顺。
4. “提示词和图片”缺少能够表现完整制作过程的沉浸式总览。

现有主流程保持不变：

```text
全屏片头
  → 完整成片
  → 片后选择
      ├─ 复盘手记
      └─ 提示词和图片
```

“复盘手记”和“提示词和图片”仍然只能在成片之后进入，不提前放到首页主视觉中。

## 2. 不可破坏的内容边界

本轮所有视觉和交互改造必须服从以下内容约束：

- 复盘正文中的 51 处案例媒体按原 Markdown 的位置与顺序保留，其中 25 张图片、26 段视频。
- 同一个媒体在正文中重复出现时，仍按原文重复展示，不合并、不移动。
- 制作档案包含 72 个案例、138 次图片出现、137 张不同图片；重复图片仍保留为两次出现。
- 制作档案的排序使用当前构建数据中的白板视觉顺序，不能改成文件名、创建时间或人工精选顺序。
- 图片、案例、提示词、首尾帧角色之间的映射不能重新猜测或自动替换。
- 所有新增交互只改变呈现方式，不改变原始内容组织。

## 3. 全站背景音乐

### 3.1 音乐风格

使用项目自有的本地原创极简钢琴循环，不接入外部音乐库：

- 约 72 BPM。
- 克制、温暖、带回忆感。
- 无鼓点、无突兀高潮、无明显流行歌曲结构。
- 适合长时间阅读，不与影片声音争夺注意力。
- 循环衔接处不能有明显断点或爆音。

音乐文件作为网站本地资产随站点发布，避免外链失效和版权不明确。

### 3.2 播放规则

- 浏览器允许的第一次用户交互后开始播放，不能绕过自动播放限制强行启动。
- 默认音量保持很低，使用固定在页面边缘的克制音乐开关。
- 记住访客的开关选择；关闭后刷新页面仍保持关闭。
- 进入完整成片前，BGM 平滑淡出并暂停。
- 退出影片或影片自然结束后，若访客此前没有关闭 BGM，则平滑恢复。
- 页面切换、翻页和打开案例弹层不能让音乐重新从头播放。
- BGM 加载失败时网站其余功能照常使用，只把音乐按钮显示为不可用状态。

## 4. 完整成片退出体验

完整成片仍采用沉浸式全屏播放器，但必须始终给访客明确的退出权：

- 画面右上角持续显示“退出影片”按钮，不因播放器控制栏隐藏而消失。
- 键盘 `Esc` 同样退出。
- 点击退出后立即暂停影片，不继续在后台播放声音。
- 退出后直接进入片后选择区 `#after`，不返回首页片头。
- 影片自然结束仍按现有流程进入片后选择。
- 退出或结束时清理播放器定时器和事件监听，避免再次播放时重复触发。
- 进入影片时 BGM 淡出；退出或结束后按原偏好淡入恢复。

## 5. 复盘阅读器

### 5.1 视觉基调

阅读区不再使用白色纸张被黑色页面包围的方案，改为与整站连贯的暖炭黑纸面：

- 页面背景为近黑色。
- 阅读纸面使用低饱和暖炭灰，不出现纯白大面板。
- 正文使用暖灰白，标题和细线使用克制的灰金、棕红点缀。
- 保证正文对比度和长时间阅读舒适度，不为“电影感”牺牲可读性。
- 案例图片和视频仍保持原始内容，不用统一滤镜篡改素材。

### 5.2 标题层级

- 每章的巨型章节号、章节大标题和引言只在该章第一页出现一次。
- 同章后续页面顶部只显示小节编号、小节标题和必要的章节定位。
- 页脚显示章节名与页码。
- 翻到后续页时不得重复渲染第一页的章节封面区域。

### 5.3 翻页动画

采用已确认的克制 3D 翻页效果：

- 动画约 0.62 秒。
- 下一页从左侧轴线向后翻出，上一页使用相反方向。
- 翻页中只使用轻微透视、纸张阴影和背面暗化，不加入夸张卷曲或发光。
- 动画执行期间锁住重复翻页输入，结束后立即解锁。
- 数据在首次进入阅读器时缓存；后续翻页只切换内存中的页面，不重新显示加载界面。
- 启用系统“减少动态”时，自动改为约 0.2 秒的淡入淡出。

### 5.4 媒体完整性

- 翻页边界按完整段落和完整案例划分，不在一张图片、视频或其说明中间截断。
- 复盘媒体仍在原文对应位置出现。
- 图片可放大，视频原位播放。
- 翻页动画只包裹阅读容器，不能重新排序、延迟插入或移动媒体。

## 6. 制作档案螺旋隧道

### 6.1 总览结构

“提示词和图片”的默认总览改为全屏 3D 螺旋隧道，同时保留列表模式作为搜索、筛选、无障碍和性能降级入口。

隧道参考并适配开源项目 [FranzLy/TimeChannel](https://github.com/FranzLy/TimeChannel) 的 Three.js 布局、惯性控制、点击聚焦和移动端性能策略。只复用本项目需要的隧道思想与交互，不引入相册导入、EXIF、IndexedDB 故事面板等无关能力。实现中保留 MIT 许可证声明和第三方归属。

### 6.2 顺序与纵深

- 把 `archive.cases` 中每个案例的 `images` 按当前数组顺序展平，得到恰好 138 个 occurrence。
- 第 001 张位于入口附近，后续图片沿制作顺序逐渐深入中心，第 138 张位于末端。
- 隧道为有限长结构，不循环复用图片来伪造无限空间。
- 图片约组成 17 个连续层次，层与层之间保留约 15% 的呼吸间隙；不能挤成一团，也不能散成平面照片墙。
- 自动漫游完整走完约 90 秒。
- 支持滚轮、鼠标拖动和触摸惯性控制；用户操作后自动漫游暂停，可手动继续。
- 列表模式不改变数据，只是同一份案例数据的另一种视图。

### 6.3 背景与光影

- 背景使用平滑近黑色，不使用放射条纹、旋转光束或明显的科幻隧道线。
- 允许少量没有明确边缘和方向的暗紫、冷灰散射光。
- 纵深只由图片的尺寸变化、遮挡关系、密度和消失点形成。
- 图片边框只保留轻微亮边和阴影，不使用强霓虹光圈。

### 6.4 末尾快速回溯

到达第 138 张后，隧道中心显示“快速回溯”按钮：

- 点击后在约 3.2 秒内沿原顺序高速反向移动。
- 回溯过程能看到图片反向掠过，不能瞬间跳回。
- 使用先加速、后减速的曲线，最后平稳停在第 001 张。
- 回溯期间暂时锁住拖动、滚轮和卡片点击。
- 回到入口后恢复正常浏览和自动漫游控制。
- 设计 Demo 中的“预览末尾”是测试入口，正式网站不保留。

## 7. 案例点开状态

### 7.1 弹层形态

点击隧道中的任意图片后，不跳到新页面：

- 暂停当前相机位置，并记住精确进度。
- 在画面中央显示悬浮案例卡片。
- 卡片底板为约 44% 不透明的深色，外围压暗约 6%；身后的隧道仍然清楚可辨。
- 图片本身始终保持 100% 不透明，不通过降低图片透明度制造玻璃感。
- 桌面端卡片左侧显示图片组、右侧显示案例信息和提示词。
- 手机端改为图片在上、提示词在下。
- 关闭后回到点开前的精确隧道位置，不从入口重新开始。

### 7.2 案例分组

隧道中展示的是 138 次图片出现，但点开后展示的是图片所属的完整案例：

- 13 个单图案例：显示一张图。
- 58 个双图案例：两张图上下排列，首帧在上、尾帧在下，并分别标记角色。
- 1 个九图剪辑参考案例：显示完整九宫格。
- 点击双图案例中的任意一张，都打开同一个完整双图案例，不能只显示被点击的一张。
- 案例卡片显示案例编号、图片出现范围、标题、类型、全部角色和完整提示词。
- 提供“复制提示词”“上一个案例”“下一个案例”和关闭。
- 上一项、下一项按 72 个案例移动，不在同一个双图案例中重复停留两次。

## 8. 状态与组件边界

建议把本轮能力拆为相互独立的状态模块：

1. `audio manager`：BGM 加载、偏好、淡入淡出、影片互斥。
2. `film controller`：完整成片进入、退出、结束和清理。
3. `review reader`：页面缓存、章节首页、翻页方向和动画锁。
4. `archive tunnel`：138 occurrence 布局、相机进度、自动漫游和回溯。
5. `archive case modal`：从 occurrence 解析所属案例、媒体组布局和焦点管理。

关键状态转换：

```text
档案浏览
  ├─ 点击图片 → 案例弹层 → 关闭 → 原位置
  ├─ 到达末尾 → 等待回溯 → 快速回溯 → 入口
  └─ 切换列表 → 列表浏览 → 返回隧道 → 保留进度
```

## 9. 响应式与降级

- 桌面端使用完整 3D 隧道和居中横向案例卡片。
- 手机端减少同时可见的远景图片数量、阴影和特效，案例卡片上下排列。
- WebGL 不可用、设备性能不足或初始化失败时，自动进入现有列表模式。
- 开启“减少动态”时默认使用列表模式，或提供明确的“进入 3D 隧道”选择；回溯改为快速淡变而非强制高速运动。
- 所有图片提供替代文字；所有按钮可通过键盘操作。
- 案例弹层打开时焦点进入弹层，`Esc` 关闭，关闭后焦点回到原图片。
- 完整成片和案例弹层的 `Esc` 行为按最上层界面处理，不能互相误触发。

## 10. 异常处理

- BGM 失败不阻断页面。
- 影片退出必须立即停止声音，即使淡出动画失败。
- 复盘数据首次加载失败时显示重试；一旦成功缓存，翻页不再出现加载页。
- 隧道初始化失败时进入列表模式并提示“3D 总览暂不可用”。
- 单张图片加载失败时保留其 occurrence 和案例位置，显示缺失占位，不跳过它。
- 案例图片数量与数据声明不一致时显示可诊断提示，不能自动换图补位。
- 路由离开档案页时释放 Three.js 几何体、材质、纹理、动画帧和事件监听。

## 11. 验收要求

### 11.1 内容与映射

- 展平结果必须为 138 次 occurrence、137 张不同图片、72 个案例。
- 第 001 张与第 138 张路径和当前数据一致。
- 重复图片保留两次出现。
- 58 个双图案例均显示上下两张图，角色顺序与数据一致。
- 九图案例显示九张，不能裁成代表图。
- 复盘 51 处媒体的位置和顺序签名与构建数据一致。

### 11.2 功能

- 第一次用户交互后 BGM 可启动，偏好可保存。
- 进入影片时 BGM 淡出；退出和结束后按偏好恢复。
- 影片退出按钮和 `Esc` 均有效，退出后到片后选择。
- 阅读器第一页显示章标题，后续页不重复。
- 连续翻页不出现加载画面；动画期间重复点击不会错页。
- 隧道滚轮、拖动、触摸、暂停和继续均有效。
- 点击任意 occurrence 能打开正确完整案例。
- 快速回溯从末尾返回入口且最终停在第 001 张。
- 列表降级、复制提示词、上一案例、下一案例、关闭和焦点返回均有效。

### 11.3 视觉与性能

- 背景无放射条纹和旋转光束。
- 图片层距有间隙但仍形成连续纵深。
- 案例卡片底板半透明，图片自身不褪色。
- 首尾帧上下排列，首帧在上。
- 复盘无白色纸面黑边，章标题只出现一次。
- 桌面和手机均无横向溢出、控件遮挡或不可退出状态。
- 真实浏览器中检查长时间自动漫游、路由往返后的内存和帧率。

## 12. 实现范围

本轮只实现本文明确的体验升级。不会新增账号、评论、后台编辑、社交分享、在线上传图片、自动生成提示词或公开投稿功能。

正式实现必须从测试开始，并在完成后执行数据重建、全部自动化测试以及桌面/手机真实浏览器验收。
